# GOHIF Changelog

All notable changes to the Global One Health Intelligence Framework (GOHIF) are documented in this file.

The project follows Semantic Versioning and milestone-based releases.

---

# Versioning Scheme

Major.Minor.Patch

Example:

* v0.1.0
* v0.2.0
* v0.3.0
* v1.0.0

Definitions:

**Major**

* Scientific or architectural milestones.

**Minor**

* New framework modules.

**Patch**

* Bug fixes, documentation improvements, refactoring, and minor enhancements.

# Change Management Policy

Every release must include:

* Objectives completed
* Validation completed
* Documentation updated
* MRD updated
* MDD updated
* Git commit
* Git tag
* Release notes

No release is considered complete without documentation.

---

# Release Approval

Every official release requires approval by the Principal Investigator after scientific and engineering review.
