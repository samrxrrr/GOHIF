# GOHIF Prompt Governance

Version: 1.0

Status: In Progress

---

## Purpose

Prompt governance ensures that AI interactions are reproducible, transparent,
and reviewable.

---

## Requirements

Prompts should:

- state objective
- specify context
- preserve provenance
- avoid ambiguous instructions
- support reproducibility

---

## Documentation

Important prompts used for evidence processing or governance shall be archived
with associated outputs and review metadata.
