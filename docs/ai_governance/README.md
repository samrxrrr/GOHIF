# GOHIF AI Governance

Version: 1.0

Status: In Progress

Phase: Phase 2D

---

## Purpose

This package defines the operational governance governing the use of artificial
intelligence throughout GOHIF.

It complements the conceptual AI Framework documented within the Master
Development Document by specifying operational policies, governance controls,
audit procedures, and responsible AI requirements.

---

## Scope

Applies to:

- LLM-assisted development
- Evidence synthesis
- Dataset prioritisation
- Knowledge extraction
- Future predictive models
- Explainable AI
- Human review
