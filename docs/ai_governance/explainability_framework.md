# GOHIF Explainability Framework

Version: 1.0

Status: In Progress

---

## Purpose

This framework establishes the explainability requirements for all artificial
intelligence components used within GOHIF.

---

## Principles

AI outputs shall be:

- understandable
- traceable
- reproducible
- evidence linked
- scientifically interpretable

---

## Explainability Requirements

Every governed AI output should identify:

- input evidence
- processing objective
- model used
- prompt or workflow version
- supporting evidence
- reviewer

---

## Governance

AI outputs lacking sufficient explainability shall not be incorporated into
governed scientific workflows.
