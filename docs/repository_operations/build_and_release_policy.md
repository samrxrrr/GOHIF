# GOHIF Build and Release Policy

Version: 1.0

Status: In Progress

---

## Purpose

This policy governs how repository releases are prepared, reviewed, and
published.

---

## Release Requirements

Before a release:

- documentation shall be current
- governance reviews completed
- validation records available
- version updated
- release notes prepared

---

## Release Types

- major
- minor
- patch

---

## Governance

Only approved releases may be designated as official GOHIF versions.
