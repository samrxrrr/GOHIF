# Philosophy

GOHIF follows a discussion-driven scientific development lifecycle.

Scientific discussion always precedes implementation.

Documentation is part of the scientific process rather than an afterthought.

Every frozen milestone becomes an immutable project artifact.

History is never overwritten.

Corrections generate new versions.
