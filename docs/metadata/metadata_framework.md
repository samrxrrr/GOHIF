# Purpose

The Metadata Framework establishes the governance principles, architectural standards, and metadata requirements for every dataset, document, computational artifact, software component, workflow, and scientific resource managed within the Global One Health Intelligence Framework (GOHIF).

It provides a unified metadata architecture that enables interoperability, traceability, reproducibility, discoverability, and long-term sustainability.

---

# Objectives

The framework aims to:

- Standardize metadata across all GOHIF domains.
- Enable consistent resource documentation.
- Improve scientific reproducibility.
- Support automated synchronization.
- Facilitate FAIR compliance.
- Ensure provenance tracking.
- Enable future public data dissemination.
- Support computational implementation.

---

# Governance Principles

All metadata shall adhere to the following principles:

1. Completeness
2. Consistency
3. Accuracy
4. Traceability
5. Reproducibility
6. Machine Readability
7. Human Readability
8. Interoperability
9. Version Control
10. FAIR Compliance

# Metadata Levels

GOHIF metadata is organized into five hierarchical levels.

## Level 1

Project Metadata

Examples:

- Project title
- Version
- Repository
- License
- Authors

---

## Level 2

Domain Metadata

Examples:

- Human Health
- Animal Health
- Environmental Health
- Food Chain
- Plant Health
- Genomics
- Knowledge Resources
- Metadata
- Validation

---

## Level 3

Dataset Metadata

Examples:

- Dataset identifier
- Source
- Collection date
- Geographic coverage
- Organism
- Data modality

---

## Level 4

Resource Metadata

Examples:

- Files
- Documents
- Scripts
- Models
- Figures
- Tables

---

## Level 5

Artifact Metadata

Examples:

- Generated outputs
- Intermediate files
- Validation reports
