# Purpose

The Controlled Vocabulary establishes standardized terminology for describing datasets, documentation, computational artifacts, workflows, and scientific resources within the Global One Health Intelligence Framework (GOHIF).

Its objectives are to:

- eliminate ambiguity
- improve metadata consistency
- enable semantic interoperability
- support automated validation
- facilitate FAIR compliance
- prepare GOHIF for ontology integration and knowledge graph development

---

# Governance Principles

Controlled terms shall be:

- unambiguous
- consistent
- documented
- reusable
- version controlled
- machine-readable
- internationally recognized where possible
