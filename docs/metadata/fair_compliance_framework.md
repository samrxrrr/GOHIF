# Purpose

The FAIR Compliance Framework establishes the policies, standards, and governance mechanisms that ensure all resources managed within the Global One Health Intelligence Framework (GOHIF) adhere to the FAIR Guiding Principles: Findable, Accessible, Interoperable, and Reusable.

This framework supports long-term scientific reproducibility, transparent data stewardship, computational interoperability, and responsible data sharing.

---

# Objectives

The FAIR Compliance Framework aims to:

- Ensure all resources are discoverable.
- Promote standardized metadata.
- Enable persistent identification.
- Support interoperable data exchange.
- Improve scientific reproducibility.
- Encourage responsible data reuse.
- Facilitate integration with public repositories.
- Align GOHIF with international best practices.

---

# FAIR Principles

GOHIF adopts the four foundational FAIR principles.

## Findable

Resources shall be:

- assigned globally unique identifiers
- described using rich metadata
- indexed within GOHIF registries
- searchable through standardized metadata
- linked to related resources

### Implementation

- GOHIF Resource IDs
- Dataset Registry
- Domain Registry
- Metadata Dictionary
- Persistent identifiers (DOI, accession numbers where available)

---

## Accessible

Resources shall:

- use standardized access mechanisms
- document access restrictions
- preserve metadata even if data are withdrawn
- define licensing information
- specify authentication requirements when applicable

### Access Categories

- Open
- Public
- Restricted
- Controlled
- Internal

---

## Interoperable

Resources shall:

- use controlled vocabularies
- follow community metadata standards
- adopt standard identifiers
- support machine-readable formats
- reference established ontologies

### Supported Standards

- Dublin Core
- DataCite
- ISO 11179
- EDAM Ontology
- OBO Foundry
- W3C PROV
- HL7 FHIR Metadata Guidance

---

## Reusable

Resources shall include:

- complete provenance
- licensing information
- version history
- quality assessments
- validation status
- recommended citation

Resources should remain reusable across future GOHIF releases whenever scientifically appropriate.

---

# FAIR Assessment Criteria

Every resource should be evaluated against the following criteria:

## Findability

- Persistent identifier assigned
- Metadata completed
- Registered within GOHIF
- Searchable

## Accessibility

- Access policy documented
- Retrieval method documented
- License defined

## Interoperability

- Controlled vocabulary used
- Standard identifiers used
- Machine-readable format
- Ontology alignment

## Reusability

- Provenance complete
- Quality assessment completed
- Version identified
- Citation available

---

# FAIR Metadata Requirements

Mandatory metadata shall include:

- Resource Identifier
- Resource Name
- Description
- Domain
- Version
- Owner
- Creation Date
- License
- Access Level
- Provenance
- Validation Status

---

# Compliance Levels

GOHIF defines three FAIR compliance levels.

## Level 1

Basic Compliance

Mandatory metadata completed.

---

## Level 2

Enhanced Compliance

Metadata, provenance, controlled vocabulary, and quality documentation completed.

---

## Level 3

Full FAIR Compliance

Complete metadata, provenance, ontology alignment, validation, reproducibility documentation, and long-term preservation strategy implemented.
