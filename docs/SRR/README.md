Status: Frozen

## Purpose

Scientific Review Records (SRRs) capture the scientific evaluation performed before any major project decision is frozen.

SRRs document:

- Scientific question
- Evidence reviewed
- Alternative approaches
- Strengths
- Weaknesses
- Trade-offs
- Bias assessment
- FAIR considerations
- Reproducibility assessment
- Novelty assessment
- Recommendation
- PI decision

SRRs are mandatory before every domain freeze and major architectural decision.

They serve as the scientific justification that precedes updates to the MRD, MDD, MDI, Decision Log, and README.
