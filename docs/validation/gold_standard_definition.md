# GOHIF Gold Standard Definition

Version: 1.0

Status: In Progress

---

## Purpose

Gold standards provide authoritative reference points against which GOHIF
datasets, workflows, AI outputs, and analytical methods are evaluated.

---

## Acceptable Gold Standards

Reference standards may include:

- internationally curated databases
- peer-reviewed benchmark datasets
- regulatory reference resources
- consensus scientific guidelines
- expert-curated annotations
- validated public repositories

---

## Selection Criteria

Gold standards shall be:

- scientifically accepted
- publicly documented where possible
- reproducible
- versioned
- traceable
- relevant to the validation objective

---

## Governance

Changes to approved gold standards require:

- scientific justification
- governance review
- version update
- documentation in the decision log
