# GOHIF Drug Target Discovery Module

Purpose:
Prioritize pathogen-associated therapeutic targets using
knowledge graph, biological evidence, and explainable AI.

Target features:

- Pathogen association
- Domain connectivity
- Network importance
- Evidence support
- Essentiality score
- Drug accessibility
- Structural availability

Future integration:

- UniProt
- STRING
- DEG databases
- PDB
- DrugBank
- ChEMBL
